# 本地夹具说明

此目录只保留本说明文件。不要提交任何夹具、图纸、截图、PDF、DWG、DXF、渲染图、OCR 输出或本地验证记录。

若在本地执行表示回归，验证记录应至少包含以下字段：

- `fixture_origin`：固定为本地来源标识。
- `source_scope`：说明本地审查使用的已授权范围，不记录私有路径或散列。
- `ground_truth_direction`：说明比较方向，例如左侧污染、右侧修正。
- `left_verdict` 和 `right_verdict`：使用 `疑似不一致`、`一致` 或 `证据不足`。
- `visible_differences`：记录覆盖、遮挡、可读性和位置绑定方面的可见差异。
- `uncertainty_section`：记录字体、转换、图层、裁切或其他环境限制。

记录只能支持表示和可读性结论，不能声称结构安全、设计批准或施工可行性。
